## 模块功能与移动端（Android）适配建议

| 业务模块 | Web端功能特征 | 安卓移动端 (APP/PDA) 设计建议 | 核心后端接口 |
| :--- | :--- | :--- | :--- |
| **01 登录与鉴权** | 租户空间、专属用户ID、密码、SVG图形验证码 | 1. 记住租户代码与账号，支持生物识别（指纹/人脸）快速登录<br>2. 传递 `client_type=android` 自动获赠 **30天超长免登 Token**<br>3. 扫二维码配置租户空间代码 | `POST /api/auth/login`<br>`GET /api/auth/captcha` |
| **02 经营工作台** | 指标卡、30天趋势图、待处理待办、饼图/柱状图 | 1. 移动端作为“首页”Tab，顶部卡片可左右滑动切换关键KPI<br>2. 待处理事项支持一键审批/驳回手势操作<br>3. 浮动动作按钮（FAB）呼出快捷开单菜单 | `GET /api/dashboard`<br>`GET /api/me` |
| **03 基础资料** | 商品列表、多级售价、客户信用额度、仓库 | 1. 顶部集成条码扫描器（调用摄像头或工业 PDA 红外扫描）<br>2. 商品卡片展示大图缩略图、现存库存与多级售价<br>3. 客户列表支持“一键拨号”、“导航到地址” | `GET /api/masters/:kind`<br>`POST /api/masters/:kind`<br>`PUT /api/masters/:kind/:id` |
| **04 采购管理** | 采购订单、采购入库、明细核算、流转状态 | 1. **仓库收货扫码入库**：扫描条码直接带出商品并累加实收数量<br>2. 支持批量拍照上传纸质随货送货单作为单据附件<br>3. 审批流手势左滑“审核”，右滑“退回” | `GET /api/documents?module=purchase`<br>`POST /api/documents`<br>`POST /api/documents/:id/actions/:action` |
| **05 销售管理** | 销售出库单、零售开单、销售订单、毛利控制 | 1. **手机开单即出库**：支持业务员在客户现场开单<br>2. 集成蓝牙便携热敏打印机，开单后即时打印销售小票/出库单<br>3. 支持生成单据分享海报/PDF，一键分享至微信客户 | `GET /api/documents?module=sales`<br>`POST /api/documents` |
| **06 库存管理** | 分仓库在库结存、出入库流水、库存调拨、盘点 | 1. **移动PDA盘点**：扫描货位与条码，录入实盘数，自动对比账面差异并一键生成盘点单<br>2. 仓库库位调拨扫码出入库校验 | `GET /api/inventory/balances`<br>`GET /api/inventory/transactions` |
| **07 往来管理** | 客户应收、供应商应付、账龄分析、收款核销 | 1. 财务收款现场录入，支持拍照上传转账电子回单<br>2. 客户欠款红黄绿账龄警示，逾期账单催收提醒 | `GET /api/finance/bills`<br>`GET /api/finance/aging`<br>`POST /api/documents` |
| **08 价格管理** | 基础进价、售价、零售限价策略 | 1. 扫商品条码快速查价与查看近期进出价历史<br>2. 具备主管权限时支持移动端调价审批 | `GET /api/prices`<br>`PUT /api/prices` |
| **09 报表中心** | 进销存明细表、销售毛利统计表、收发存汇总 | 1. 移动端折线图与柱状图自适应适配（MPAndroidChart 或 Compose-Charts）<br>2. 支持一键导出 Excel 分享到移动端应用 | `GET /api/reports/:kind` |
| **10 预警中心** | 库存不足预警、保质期超期、应收逾期账单 | 1. 结合 Android 系统通知栏推送（Notification Manager）<br>2. 桌面角标（Badge）实时显示未处理预警数量 | `GET /api/warnings`<br>`POST /api/warnings/ack` |
| **11 系统设置** | 业务参数、用户与权限、编号规则、操作审计 | 1. 移动端主要提供个人设置、清除本地缓存、检查 APP 版本更新<br>2. 复杂角色权限配置建议优先在 Web 端操作，移动端展示只读权限清单 | `GET /api/system/settings`<br>`GET /api/mobile/version/check` |

## 移动端技术对接标准

1. **接口鉴权请求头标准**：
   ```http
   Authorization: Bearer <64位SessionToken>
   X-Tenant-Code: <租户代码，如 xuyonghong>
   X-Platform: android
   X-Device-Id: <硬件唯一识别码，如 IMEI/AndroidID>
   Idempotency-Key: <UUID防重放与网络抖动重试凭证>
   Content-Type: application/json
   ```
2. **长效免登会话**：
   在调用 `POST /api/auth/login` 时传入 `client_type: "android"`，后端将自动授予租户 **30 天超长会话周期**，无需频繁重新输入密码。
3. **软预警响应头**：
   当请求响应头包含 `X-Quota-Warning` 时，表示租户磁盘配额已达 85% 水位线，移动端可弹出顶部横幅提醒管理员注意扩容或归档老数据。
4. **离线与断网容错**：
   移动端应在本地（如 Room DB）缓存商品、客户、供应商等高频基础资料，支持离线状态下扫描条码加入开单购物车，连网后批量提交后台核算。
