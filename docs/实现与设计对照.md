# V1.1 实现与设计对照

依据根目录《睿链进销存与往来管理系统_架构与实现设计说明书_V1.1_含授权体系.docx》实现。本文记录本次 Windows 本地版的业务覆盖及 SQLite 适配，供交付和后续维护使用。

## 技术与部署

| 设计项 | 本次实现 |
| --- | --- |
| Web 前端 | Vue 3、TypeScript、Vite、Pinia、Vue Router、Element Plus、ECharts，中文界面 |
| Go 后端 | Gin REST API，按资料、单据、库存、往来、价格、报表、授权及备份划分模块 |
| 数据库 | 按用户要求使用 SQLite，纯 Go 驱动；无需安装数据库服务或额外 DLL |
| EXE 部署 | Electron 独立桌面客户端，NSIS 可安装 EXE，自带运行环境；客户无需外部浏览器 |
| 服务地址 | 仅监听 127.0.0.1；这是本机使用版本，当前发行包未开放局域网接入或注册 Windows 系统服务 |
| 首次使用 | 空库自动创建 admin/admin；内部修改密码；数据保存在 %APPDATA%\RuilianERP\data |
| 品牌与素材 | 名称、简称和 Logo 可设置；安装包与快捷方式由 branding.json 配置；Noto Sans SC（OFL 1.1）和 MIT 图标 |
| 平台范围 | 已构建与验证 Windows x64。代码包含非 Windows 平台适配，但本次未交付或验收 Linux 可执行文件 |

## SQLite 与数据模型适配

设计书列出的模型按业务含义保留，采用共享表减少采购、销售和资金单据之间重复的状态机与审计代码。

| 业务概念 | SQLite 表 |
| --- | --- |
| 用户、角色、会话 | users、roles、sessions；角色权限使用结构化 JSON 存储 |
| 基础资料 | base_records，以 kind 区分商品、客户、仓库等资料，以 data 保存对应字段 |
| 业务单据、明细、关联与编号 | documents、document_items、document_sequences；source_id/source_item_id 追溯上游 |
| 库存、批次、流水、序列号和占用 | inventory、inventory_transactions、inventory_serials、stock_reservations；批次作为库存维度 |
| 应收/应付及核销 | bills、settlements、writeoffs、bill_offsets、settlement_offsets；side 区分 ar/ap |
| 价格、差异、预警与审计 | price_rules、cost_adjustments、warning_ack、operation_log、idempotency |
| 授权 | system_installation、license_local、license_activation_log、license_event_log |
| 备份与任务 | backup_records、background_jobs、settings |

金额存储为整数分，数量与单价为万分之一整数，乘除使用定点计算。库存数量、账款、审核状态及核销关系在同一事务内更新。SQLite 启用 WAL、FULL 同步、外键和忙等待；写事务使用 BEGIN IMMEDIATE 替代 PostgreSQL 的 SELECT FOR UPDATE。SQLite 同一时刻只有一个写事务，因此不能据此宣称支持分布式高并发部署。

同一数据目录只能启动一个服务；恢复前也须取得该目录的排他锁。关键接口持久化幂等键；单据版本号阻止旧页面覆盖新修改。审核失败回滚全部影响，已审核业务通过受控红冲或退换货纠正。

## 备份口径与运行边界

SQLite WAL 是当前数据库事务日志，不等同于 PostgreSQL 可持续归档及任意时点恢复的 WAL。本版采用 VACUUM INTO 在线生成独立快照，再执行数据库、外键及业务流水一致性检查，并复制至已配置的独立目录。未将正在使用的主数据库文件直接当作备份。

默认运行期间每 15 分钟生成快照，保留最近 192 份，另有每日 14 份、每周 12 份、每月 12 份。任务失败最多重试三次，记录异常任务。异盘、异地目录需实际配置和可访问，默认安装不代表已经具备三份独立介质副本。

系统未实现 PostgreSQL WAL 归档、SQLite 任意时点恢复或对象存储 SDK 上传。目标为运行期间按配置间隔生成有效快照；不能在服务关闭、介质损坏、复制失败或大数据库备份耗时情况下保证 15 分钟 RPO。恢复时间取决于备份规模和介质速度，未对大规模生产数据承诺 RTO。

恢复先验证来源，复制现有数据库、WAL、SHM 与安装记录，再替换数据库并写入审计。原安装目录保留时重新校验授权；仅恢复数据库至新安装环境时保留数据读取、导出、备份，使用新的 Installation ID 向发行方申请重新绑定。

## 本版采用的业务约定

- 价格优先级在设计书推荐顺序中加入限时促销：客户专属 → 客户等级 → 促销 → 数量阶梯 → 基础价 → 指导价。关联订单默认保持订单约定价。
- 调拨审核一次完成调出与调入，未启用设计书标注为可选的在途阶段。
- 库存成本按商品、仓库、库位、批次维度移动加权；未实现其他可选成本算法。
- 库存与成本按业务日期汇总，历史业务应核对日期后录入。红冲不能越过后续库存流水。
- 经营回款率为当期净收款/当期净销售，可包含历史账款与预收；周转为当期销售成本/期初期末平均库存。界面和使用说明均展示计算口径。
- 使用内嵌桌面窗口显示界面；未实现设计书作为扩展方向列出的 POS 外设、会员、电商、外部财务、BI、在线授权服务器、订阅、远程吊销或设备数量在线校验。
- 客户安装包仅包含桌面运行环境、内嵌本机数据服务、字体、图标、说明和第三方许可。发行方私钥及授权工具位于独立的 publisher-private 目录，不进入客户安装包。

具体操作参见《使用说明》，已执行检查及交付文件校验信息参见《验收记录》。
