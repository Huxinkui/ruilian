# 发行方授权管理工具

`publisher-private` 是发行方专用目录，不属于客户发布包。

## 文件

- `授权管理工具.exe`：离线授权生成工具，可双击打开图形表单，也支持命令行。
- `issuer-private.pem`：Ed25519 签名私钥，当前用户与 SYSTEM 可访问。不能交给客户，也不能提交到代码仓库。
- `issued-licenses.jsonl`：图形工具生成授权时记录的签发信息；不含私钥。
- `第三方许可证.txt`：包含工具内嵌的 Noto Sans SC 字体 OFL 及依赖许可，请与工具一同保留。

与私钥匹配的公钥位于源码 `internal/licensecode/public.key`，并内置在客户 EXE 中。客户数据库备份只包含签名凭证、安装标识和授权状态，不包含发行方私钥。

## 人工签发

1. 客户进入“系统管理 → 软件授权”，复制 Installation ID。
2. 双击 `授权管理工具.exe`，在浏览器填入客户编号与 Installation ID。
3. 默认允许版本范围 `1.1.0` 至 `1.9999.9999`，授权类型 PERPETUAL、全部业务功能。
4. 生成授权码，完整复制给客户；也可保存成 UTF-8 `.license` 文本文件。
5. 客户激活后可以永久离线使用，不需要在线授权服务器。

图形工具绑定随机本机端口和访问凭证。浏览器关闭后工具仍运行；关闭它启动的终端窗口结束服务。

## 命令行

```powershell
.\授权管理工具.exe issue --key .\issuer-private.pem --installation "客户提供的32位安装标识" --customer "KH-2026-001" --from 1.1.0 --to 1.9999.9999 --out ".\KH-2026-001.license"
```

可选参数 `--features` 用逗号指定功能，例如 `base,purchase,sales,inventory,finance,price,reports`；默认 `*` 代表全部业务功能。激活、备份、导出与数据查看能力不会因为缺少某个业务模块而被破坏。

核对密钥：

```powershell
.\授权管理工具.exe check-key --key .\issuer-private.pem --public "..\internal\licensecode\public.key"
```

只有建立全新发行体系时才运行 `keygen`。工具拒绝覆盖已有私钥。新密钥需要重新构建客户 EXE，不能用新私钥为旧公钥客户端签发授权。

## 升级与迁移

后续升级保留原私钥和公钥。构建脚本会验证两者匹配。生成新版本范围的授权时，应按客户实际购买范围设置起止版本。

客户仅恢复数据库至新机器时，会看到新的 Installation ID。核对迁移对象后为新安装标识重新签发授权，原有业务数据不受影响。离线模式不提供远程吊销旧授权、在线订阅或设备数量在线校验；这些属于设计书列出的后续扩展范围。

请将私钥另外备份至发行方受控的独立介质。私钥遗失后，不能仅凭客户端公钥重建原签发能力。
