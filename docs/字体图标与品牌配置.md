# 字体、图标与品牌配置

默认产品名称为“进销存与往来管理系统”，默认桌面程序名称为“进销存管理系统”。界面不再使用“睿链”作为默认品牌。

## 在软件内修改名称与 Logo

使用管理员登录，进入“系统管理 → 企业与业务参数 → 软件名称与 Logo”。

- **软件名称**：1～64 个字符，用于登录页、窗口标题、页脚、授权页。
- **品牌简称**：1～12 个字符，用于导航与面包屑。
- **软件 Logo**：本地 PNG/JPEG，文件不超过 512 KB，宽高均为 16～1024 像素。可点击“恢复默认图标”。

点击“保存品牌设置”立即生效。设置存储在 SQLite 中，重启保留并随数据库备份、恢复。企业名称是独立的业务设置，用于单据抬头。

此处修改界面和运行中的窗口图标。Windows 安装包文件名、已安装 EXE 和快捷方式名称在打包时确定；修改这些名称请按下一节重新打包。

## 发行时配置安装包与快捷方式

编辑项目根目录 `branding.json`：

```json
{
  "app_name": "进销存与往来管理系统",
  "brand_short": "进销存",
  "desktop_name": "进销存管理系统",
  "installer_name": "进销存管理系统安装程序",
  "shortcut_name": "进销存管理系统",
  "publisher": "",
  "copyright": "",
  "logo_file": ""
}
```

`desktop_name` 决定 EXE 文件名；`installer_name` 为安装包前缀，后面自动追加版本与架构；`shortcut_name` 决定桌面、开始菜单名称。`publisher` 和 `copyright` 可填写自己的真实发行信息，默认为空。`logo_file` 可填项目内 PNG/JPEG 的相对路径或本机绝对路径，留空使用默认几何图标。名称不能包含 Windows 文件名禁用字符。

在已配置开发工具的环境中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1 -SkipInstall
```

脚本会生成默认品牌数据、应用图标、窗口启动页、Windows 版本资源和 NSIS 安装包。字体和许可证进行 SHA-256 校验。应用内部产品 ID、安装标识、数据库位置和已有授权密钥保持兼容；仅改变显示品牌不会使原授权失效，也不会重置已有密码或数据。升级时保留数据库内已经保存的品牌设置。
